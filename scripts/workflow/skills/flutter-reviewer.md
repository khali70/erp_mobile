# Skill: Flutter Reviewer

## Purpose

Review generated code before completion.

## Responsibilities

Review:

- Clean Architecture
- SOLID Principles
- Naming Conventions
- Error Handling
- Performance
- Readability
- Maintainability

## Review Checklist

### Architecture

- Layer separation respected
- No business logic in UI
- No direct API calls from widgets

### Code Quality

- Meaningful names
- Small focused classes
- Reusable widgets

### Performance

- Avoid unnecessary rebuilds
- Avoid duplicated widgets
- Avoid unnecessary state updates

### Flutter Best Practices

- Proper state management
- Proper dependency injection
- Proper navigation
- Proper localization support

### Final Output

Provide:

- Issues Found
- Suggested Improvements
- Final Approval
