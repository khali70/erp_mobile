# Skill: Figma To Flutter

## Purpose

Convert Figma designs into Flutter UI.

## Responsibilities

- Analyze layouts
- Analyze typography
- Analyze spacing
- Analyze colors
- Analyze components
- Detect reusable widgets

## Rules

Use:

- AppColors
- AppSpacing
- TextStyles
- ScreenUtil

Avoid:

- Hardcoded dimensions
- Duplicated widgets
- Inline styling

## Output

Generate:

- Screens
- Widgets
- Layouts

Do not generate:

- Repositories
- UseCases
- API Logic

Focus only on UI.
